## English Version

### 🛠 Supported Protocols
Flare Desktop supports a wide range of modern protocols, including:
- **VLESS** (with REALITY & XHTTP support)
- **Shadowsocks**
- **Hysteria 2**
- **VMess / Trojan**
- And many others!

### ✨ Advanced Features
Flare offers professional-grade tunnel settings to bypass censorship and optimize your connection:
- **Fragmentation:** Split packets to evade detection.
- **Mux:** Multiple streams over a single connection for better efficiency.
- **Fake IP:** Enhance DNS performance and privacy.
- **Proxy Chaining:** Route your traffic through multi-hop proxy chains.
- **Cross-Platform:** Native builds available for Windows and Linux.

### 📡 Creating your own servers
FlareVPN supports the deployment and management of your own VPN servers based on the most modern and block-resistant protocols:
- **VLESS (with REALITY support)**
- **Hysteria 2**
- **Shadowsocks**
- **WireGuard**

### 🛠 Installation

#### Windows
1. Download `Flare.VPN_x.x.x_x64-setup.exe` or `.msi` from the [Releases](https://github.com/FlareSpace/FlareVPN-Desktop/releases) page.
2. Run the installer and follow the setup instructions.
3. Launch Flare VPN and get started!

#### Linux
- **Debian / Ubuntu**: Download the `.deb` package and install via `sudo apt install ./Flare.VPN_amd64.deb`
- **Universal AppImage**: Download `.AppImage`, make it executable (`chmod +x Flare.VPN_amd64.AppImage`), and run directly.
- **Fedora / RHEL**: Download the `.rpm` package and install via `sudo dnf install ./Flare.VPN_x86_64.rpm`

## Русская Версия

Новый уровень защиты и конфиденциальности для десктопных платформ (Windows и Linux).
Flare — это мощный VPN-клиент с открытым исходным кодом, созданный для обеспечения гибкости, безопасности и высокой производительности. Flare Desktop предоставляет современный, быстрый и удобный интерфейс для управления вашими защищенными туннелями на базе кастомного ядра `sing-box`.

### 🛠 Поддерживаемые протоколы
Flare Desktop поддерживает широкий спектр современных протоколов:
- **VLESS** (с поддержкой REALITY и XHTTP)
- **Shadowsocks**
- **Hysteria 2**
- **VMess / Trojan**
- И многие другие!

### ✨ Продвинутые функции
В Flare доступны профессиональные настройки туннелей для обхода цензуры и оптимизации соединения:
- **Фрагментация:** Разделение пакетов для обхода средств обнаружения.
- **Mux:** Мультиплексирование потоков для повышения эффективности.
- **Fake IP:** Улучшение производительности DNS и конфиденциальности.
- **Proxy Chaining:** Маршрутизация трафика через цепочки прокси (multi-hop).
- **Кроссплатформенность:** Нативные сборки для Windows и Linux.

### 📡 Создание своих серверов
FlareVPN поддерживает развертывание и управление собственными VPN-серверами на базе самых современных и устойчивых к блокировкам протоколов:
- **VLESS (с поддержкой REALITY)**
- **Hysteria 2**
- **Shadowsocks**
- **WireGuard**
